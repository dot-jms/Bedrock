# Bedrock

Static site, no build step.

- `index.html` access gate (edit `KEYS` in the script to change keys). Opens the portal in an about:blank tab.
- `portal.html` Home and Games. The Games tab opens Bedrock Games in an about:blank tab (change `GAMES_URL` in the script).
- `styles.css`, `shared.js` shared styling and the space background
